和 mac2 一样的

  • 780×580 固定窗、188 侧栏、30 底栏
  • 行高 68 / 缩略图 46 / 角标 22
  • 四态药丸：已同步 / 传输中 / 仅本机 / 失败
  • 悬停缩略图 450ms 出气泡，220ms 关
  • 单击行 = 复制，双击 = 预览
  • 双态空态、键帽、像素字号

Windows 化的

  • 自绘标题栏：只留最小化 / 关闭，关闭收进托盘
  • 托盘：左键开窗、右键菜单、双击也开窗（不切换）
  • 热键 Alt+Space / Ctrl+Shift+V，键帽写文字
  • 文件 → 资源管理器；图片 → 默认看图；链接 → 默认浏览器
  • 清空确认是窗口内遮罩，不弹第二个窗口
  • 设置多一个「高级」组（探测 / 日志 / 配置目录）
