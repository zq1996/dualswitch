从 Frset 借了什么

  • 单强调色 #4E87FF：去掉渐变按钮，主按钮扁平填充 + hover 加深
  • 图标三档：20px 工具行 / 24px 强调 / 44px 列表类型图标
  • 行的解剖：图标 + 主文案 + 副行（来源·时间·大小·类型，圆点分隔）
  • 空态插画 + 主副文案，且「筛选无结果」和「本来就是空」文案分开
  • 状态药丸即按钮：失败 / 仅本机态点药丸直接重试
  • 设置分组标题（通用 / 热键 / 显示器…），不再是平铺长列表

功能映射（部分重合）

剪贴板列表 → 保留并升级 设置页 → 保留加分组 菜单栏常驻 → 一致
画面归属三态 → 新增状态卡 设备卡 ×2 → 新增 远端代发切换 → 按钮里
AI 工具 / 搜索引擎 → 不要 日历 / 截图 / 取色 → 不要 Pro 订阅 → 不要 悬浮剪贴板 → 违反单窗口

可点的交互

  • 上方控制条切页面 / 画面归属 / 列表数据 / 明暗
  • 主界面点「切换到 Mac」看 切换中 → 成功 三段
  • 剪贴板点失败 / 仅本机的药丸会重试并变绿
  • 剪贴板筛选 chips 切换，看空态与筛选空态
  • 设置页开关、分段控件可点

保留了既有硬约束：整个应用只有一个窗口（剪贴板/设置都是窗口内翻页， 不是独立面板）；画面归属三态的置灰逻辑；「仅本机」与「失败」分开。
