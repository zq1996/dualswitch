
| 元素         | 规格                                            | 状态       |
| ---------- | --------------------------------------------- | -------- |
| 缩略图        | 46×46 r10；图片 cover；文字/链接/文件用类型图标              | 🔄 36→46 |
| **来源系统角标** | 缩略图**右下角** 19×19 圆角块：Mac=灰底白苹果 / Win=蓝底白四格    | 🆕       |
| 标题         | 12.5px，2 行省略；代码用等宽 11px                       | ✅        |
| 元信息行       | `来源(加粗) · 应用 · 时间 · 大小[· 尺寸] · 类型`，2.5px 圆点分隔 | 🔄       |
| 状态药丸       | 右上角；已同步=绿/传输中=蓝+百分比/仅本机=灰/失败=红                | ✅ 四态     |
| hover 动作   | 复制 / **按类型分派**：图片→预览、文件→访达、链接→打开链接 / 删除       | 🆕       |

**打开方式按类型分派**（用户确认：不是所有都用访达）：

| 类型 | 行内/预览窗动作    | 实现                                                                      | 理由                 |
| -- | ----------- | ----------------------------------------------------------------------- | ------------------ |
| 图片 | **用图片预览打开** | `NSWorkspace.open(_:withApplicationAt: Preview.app)` 或 `QLPreviewPanel` | 图片消费场景是「看图」不是「管文件」 |
| 文件 | **在访达中显示**  | `NSWorkspace.activateFileViewerSelecting`                               | 文件要的是定位/拖拽/后续操作    |
| 链接 | 打开链接        | `NSWorkspace.open(url)`                                                 | —                  |
| 文字 | 仅复制         | 写回 NSPasteboard                                                         | —                  |

**跨系统合理性**（用户问「两个系统的推送剪贴板，这样合理吗」的结论）：

- 契约 `CLIPBOARD-SYNC-CONTRACT.md` P2 明确 **文件/目录不跨端同步**，只有文字+图片在同步  
  （`ClipItem.kind: "text"|"image"|"mixed"`）。
- 因此：**图片**可能来自对端（内存 PNG payload，无本地路径）→ 用「图片预览打开」合理  
  （预览窗渲染的是 payload，预览打开走临时文件或 QLPreviewPanel）；  
  **文件**条目只可能是本机产生的（对端文件根本不过来）→ 「访达显示」合理，因为文件本来就在本地。
- 若未来 P2 落地文件同步，接收方需要落地到缓存目录，届时「访达显示」指向缓存路径，  
  语义仍然成立。

**用户反馈修正**：角标是**来源系统**不是来源应用 —— 从 Mac 复制的显 Mac 角标，  
Windows 复制的显 Windows 角标。应用名（微信/Safari…）降级为元信息行文字。

### 3.4 悬浮预览窗 🆕（用户反馈三轮修正定稿）

**触发**（Frset 源码/字符串证据）：

- 只在**缩略图**上悬停触发 —— 原文 `Show preview when hovering over clipboard icons`  
  =「悬浮在剪贴板**图标**上时展开预览」，**不是整行**（整行悬浮会误触发+遮列表）
- 打开延时 **450ms**：Frset 用 `hoverPreviewOpenDelay` + `__hoverPreviewOpenWorkItem`  
  （DispatchWorkItem 延时）；关闭延时 220ms（`hoverPreviewCloseDelay`）
- 预览窗本身 hover 可停留（`__isPreviewPopoverHovered`）；滚动/换页/换行立即关

**位置**：气泡放缩略图**左侧**，箭头朝右指向缩略图 —— 不遮挡右侧列表文字。  
左侧放不下才翻右侧；垂直方向箭头对准缩略图中线；超出视口自动夹紧。

**尺寸**（Frset：`MainPanelPreviewContentSizePreferenceKey` / `MeasuredSize`）：  
**随内容自适应，不是固定宽**。分类上限：

| 类型  | 自适应   | 上限（Frset 参数名）                                                  |
| --- | ----- | -------------------------------------------------------------- |
| 图片  | 按原图比例 | max-width 412 / max-height 330（`imagePreviewMaxPopoverHeight`） |
| 文字  | 随行数   | max-width 392 / max-height 270                                 |
| 代码  | 随内容   | max-width 400 / max-height 290（`codePreviewMaxWidth/Height`）   |
| 文件卡 | 随文件名  | max-width 380                                                  |
| 链接块 | 随 URL | max-width 380                                                  |

**动画**（Frset：`SwiftUI Animation.spring(response:dampingFraction:)`）：  
弹簧入场 320ms `cubic-bezier(.22,1.2,.36,1)`，scale .9→1.015 过冲→1，transform-origin 朝锚点侧。

**视觉**：带**指向箭头**的气泡（Frset：`PopoverArrowShape`/`PreviewArrowGeometryStore`），  
r13 三层阴影、头部浅底+类型图标+状态药丸、代码块浅底描边、链接浅蓝块、底栏元信息+按钮。

**底栏按钮按类型分派**：图片→[预览]（用 Preview.app 打开）；文件→[访达]；都有 [复制]。

**结构**（对齐 macOS Quick Look 质感）：

| 区  | 内容                                                                                   |
| -- | ------------------------------------------------------------------------------------ |
| 头部 | 类型图标(14px) + 标题（省略）+ 状态药丸；浅底 `card-2`                                                |
| 正文 | 图片=大图 r9+细描边+尺寸注脚｜文字=11.5px 行高 1.8｜**代码=等宽+浅底描边块**｜文件=图标卡片+文件名+路径｜**链接=浅蓝底块+等宽 URL** |
| 底栏 | `来源 · 应用 · 时间 · 大小` + 按类型分派按钮（图片→[预览]；文件→[访达]）+ [复制]                                 |

超长文本注脚「当前已显示 60 / N 个字符」（Frset 文案）。  
按钮行为：复制 → toast「已复制」（异常态变「已重新同步」）；预览（图片）→ 用 Preview.app 打开；  
访达（文件）→ toast「在访达中显示：路径」。

**视觉基线**：圆角 14、三层阴影（外描边 .5px + 近投影 + 远投影）、  
入场 scale(.96)→1 + fade 180ms、头/底浅底区分正文区。深色模式阴影加深。

### 3.5 行内动作 🆕

hover 行尾浮现（fade 140ms），25px 圆角方钮：

| ---- | ----- | -------------------------------------------------------------- |
| 复制   | 全部    | toast「已复制」；异常态 → 触发重试变绿                                        |

### 3.6 状态药丸 = 重试按钮 🔄（Frset 同款，现有已有）

- 已同步/传输中：不可点，点击 toast「已复制」（Frset 双击复制语义）
- **仅本机 / 失败：点药丸直接重试**——药丸变「传输中 N%」进度条 → 240ms×4 步 → 变绿「已同步」

### 3.7 双态空态 🆕（Frset：两种空态文案必须分开）

| 场景    | 插画     | 主文案       | 副文案                           |
| ----- | ------ | --------- | ----------------------------- |
| 列表真空  | 剪贴板+加号 | 剪贴板为空     | 复制内容后会显示在这里，<br />并自动同步到另一台机器 |
| 筛选无结果 | 放大镜+×  | 当前筛选下暂无内容 | 换个筛选条件试试                      |

### 3.8 同步四态语义（保留，Frset 没有的部分）✅

| 态   | 药丸          | 可点       | 语义                 |
| --- | ----------- | -------- | ------------------ |
| 已同步 | 绿           | 否        | 对端写入成功并回 ACK       |
| 传输中 | 蓝+百分比+行下进度条 | 否        | 已发出待 ACK           |
| 仅本机 | 灰           | **是→重试** | 未配对/同步关闭/对端离线，不是错误 |
| 失败  | 红           | **是→重试** | 超时/拒绝/写入失败         |

## 8. 图标来源与提取（2026-10-21）

**背景**：用户反馈原型手绘 SVG 图标丑，「人家按钮都用的图标」。Frset 的图标在
`Assets.car` 里是矢量资产（REA `inspect-asset-catalog` 报 101 个资产名 / 320 条 rendition）。

**提取方式**：`icons/extract_car.py` —— pyobjc 加载 `CoreUI.framework` 私有接口，
`CUICatalog.imageWithName_scaleFactor_()` 取 `CUINamedImage` → `cgImage` → ImageIO 写 PNG。
20 个图标导出在 `icons/frset-extracted/`（clipboard_type_* / abc_* / settings_*）。

注意：Assets.car 内的 SVG 是差分压缩的，直接正则抽出来是乱码（踩过），
必须走 CoreUI 渲染。`icons/b64.py` 转 base64 → `icons-data.js` → `icons/inline_icons.py` 内联进原型。

**原型现状**：剪贴板文字/链接缩略图、空态插画已换 Frset 提取图。

**⚠️ 正式实现红线**：提取图仅供**设计原型比对**。`src/dualswitch/ui/assets/` 里的正式图标
必须**自己重绘**（描边粗细/圆角/光学重量参照提取图），不能把 Frset 的 PNG 直接打进产品包 ——
那是它的版权素材。平台角标（apple/windows）用 `icons/make_icons.py` 自绘那套。

## 9. 第二轮返工修订（2026-10-21 晚）

用户验收第一版实现后提的五条，全部落进代码；与上文冲突时**以本节为准**。

### 9.1 图标：一律开源图标库

- 控件图标 = **Lucide**（ISC），平台 logo = **Simple Icons**（CC0）。
  路径内联在 `ui/mac2/iconlib.py`，渲染在 `ui/mac2/icons.py`，颜色在绘制时注入。
- 平台标识两种用法：`plate_pixmap()`（62 / 32 渐变牌 + 白 logo）、
  `badge_pixmap()`（19 角标 + 1.8px 卡片色描边）。
- 不再有「自绘 SVG / PNG 素材」的图标；`ui/assets/` 只剩应用图标与菜单栏模板图。

### 9.2 剪贴板页：不留文字按钮

- 工具栏 ⏸ / 🗑、行内 hover 动作、**预览窗底栏**全部改成纯图标按钮（带 tooltip）。
- 筛选 chips 属于过滤器（文案 + 计数），保留文字。

### 9.3 暂停记录 = 真功能

`⏸` → `SyncEngine.set_paused(True)`：停止采集本机剪贴板（**仍 poll 一次并丢弃**，
避免恢复时把暂停期间的内容补发）；接收对端内容与列表照常。按钮变实心主色、图标换 ▶。

### 9.4 删除：两种语义分开

- 行内 × / 右键「删除这一条」/ 聚焦行 ⌫ → 只删这一条（`drop_record`）。
- 工具栏 🗑 → 菜单「清理 1 / 7 / 30 天前 / 清空全部…」，**清空必须二次确认**
  （写明条数、只清本机、不可撤销）。
- 任何入口都不会「点一次就全没」。

### 9.5 尺度：字号按像素

设计稿是 CSS px，Qt 用 point 会整体放大 1.33 倍。全局字体改 `setPixelSize(12.5)`，
QSS 与自绘控件统一 `Npx` / `theme.qfont(px)`。

### 9.6 设置项全部接到底层

切换模式（force 直接发 Set）/ 启用跨端剪贴板（停·重启引擎）/ 悬浮预览（关掉不弹）/
保留历史（引擎按天清理）/ 存储上限（值显）。
