v2 破了什么框架

  • 窄窗口卡片堆叠 → 宽窗口 + 侧栏导航（macOS System Settings / Frset 设置页范式）
  • 780×580，三个核心功能各占一页，侧栏带计数与运行状态
  • 切换页 hero 化：大 logo + 大标题 + 主按钮组
  • 标题栏只留系统按钮（红绿灯 + 居中标题），页内不放自绘工具钮

剪贴板 = Frset 交互全量

  • 缩略图右下角来源系统角标——从 Mac 复制的显 Mac 角标，Windows 复制的显 Windows 角标
  • 悬浮预览窗：图片放大；文字/代码全文显示（超屏内部滚动，不截断）；文件是文件卡（图标+文件名+目录）
  • 三类分开：截图（内存图片）／图片文件（访达复制，缩略图=图片内容）／普通文件（缩略图=文件瓷砖）
  • 按钮按类型分派：截图=预览；图片文件=预览+打开文件；普通文件=打开文件；链接=打开链接；都有复制与删除
  • 单击行 = 直接复制（双击才预览）；重复复制同一条不加行，只把它提到最前
  • 类型筛选 chips（文字/图片/文件/链接/异常）+ 搜索 + 暂停记录 + 清理历史
  • 双态空态文案分开（空列表 vs 筛选无结果）
  • 元信息行：来源 · 应用 · 时间 · 大小[·尺寸] · 类型；文件行给的是 来源 · 应用 · 时间 · 目录

同步四态（已同步/传输中/仅本机/失败）保留在右上角药丸 —— 这是 dualswitch 特有，Frset 没有。

可点的交互

  • 上方菜单栏弹出菜单：点图标或控制条「弹出菜单」
  • 侧栏切三页；控制条切画面归属/剪贴板数据/明暗
  • 剪贴板鼠标悬浮缩略图 → 预览窗（核心新交互）；单击行 = 复制，双击 = 预览
  • 悬浮后行内出现复制 / 预览 / 打开文件 / 删除（按类型出现）
  • 失败/仅本机药丸点击重试 → 变绿
  • 切换按钮三段动画；设置开关可点

仍然只做一个窗口 —— Frset 的悬浮剪贴板（独立面板）没抄，菜单栏菜单是系统菜单不算窗口。
