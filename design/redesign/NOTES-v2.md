## 2. 剪贴板 = Frset 交互全量（用户要求「都复制」）

已移植（除悬浮剪贴板独立窗口——那是 Frset 的窗口，用户明确不要）：

1. **缩略图右下角来源系统角标** —— Mac 复制的显 Mac 角标，Windows 复制的显 Windows 角标
   （第一版做成来源应用角标，用户纠正为来源系统）
2. **鼠标悬浮出预览窗**：图片放大、文字/代码全文（超长提示「当前已显示 N/M 个字符」）、
   文件卡片带路径、链接原文
3. **文件直达访达**：行内 hover 动作 + 预览窗底部「访达」按钮
4. 行内 hover 动作：复制 / 访达 / 打开链接 / 删除
5. 类型筛选 chips：全部 / 文字 / 图片 / 文件 / 链接 / 异常
6. 搜索、暂停记录、清理历史（工具栏图标按钮）
7. 双态空态文案分开：空列表「剪贴板为空」 vs 筛选「当前筛选下暂无内容」
8. 元信息行：**来源（加粗） · 时间 · 大小 · 尺寸 · 类型**（圆点分隔）
9. 设置页新增剪贴板分组：悬浮预览开关、保留历史、存储上限

dualswitch 特有保留：同步四态药丸（已同步/传输中/仅本机/失败）在行右上，
失败/仅本机点药丸重试。Frset 没有同步概念，这块不抄。

## 3. 重画的平台图标（替换原资产里不好看的两个）

原 `src/dualswitch/ui/assets/` 里的 `apple-logo.png` / `windows-logo.png` 用户嫌丑。
新图标在 `design/redesign/icons/`，同名同规格 256×256 RGBA：

| 文件 | 画法 |
|---|---|
| `apple-logo.png` | 自绘苹果轮廓：双叶身体 − 右咬痕 + 旋转 -35° 叶子，近黑 `#1D222B` |
| `apple-logo-dim.png` | 同形置灰 `#B9C0CB` |
| `windows-logo.png` | 自绘四格：2×2 小圆角(3px)方块，格距 10，蓝 `#2B7CD3` |
| `windows-logo-dim.png` | 同形置灰 |

注意：圆角 8px 时四格像三叶草，3px 才利落（脚本注释里记了）。
形状为**自绘几何**，非官方素材拷贝。确认后可直接覆盖 `src/dualswitch/ui/assets/` 同名文件
（`logo_pixmap(kind)` 按 `{kind}-logo.png` 加载，两端共用，覆盖即生效）。

## 4. 可交互点

- 上方控制条：页面 / 画面归属三态 / 剪贴板数据三态 / 菜单弹出 / 明暗
- 菜单栏点图标 → 弹出菜单，菜单项可点（切换/剪贴板/设置/退出都有反馈）
- 剪贴板鼠标悬浮条目 → 预览窗；行内出现动作按钮
- 失败/仅本机药丸点击重试 → 进度条 → 变绿
- 切换按钮三段动画；设备卡点击切换；设置开关/分段控件可点
