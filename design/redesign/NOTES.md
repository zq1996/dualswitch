## 1. 功能交集分析（决定谁留谁走）

两个应用都是**菜单栏常驻工具 + 剪贴板相关**，但核心功能不同：
Frset 是「剪贴板管理器 + AI 工具集」，dualswitch 是「跨端切屏 + 剪贴板同步」。

| 功能 | Frset | dualswitch | 本稿处理 |
|---|---|---|---|
| 剪贴板列表 | ✅ 本地历史 | ✅ 跨端同步 | **保留并升级**（借 44px 类型图标行 + 元信息行 + 空态插画） |
| 设置页 | ✅ 侧栏 4 组 | ✅ 四页签 | **保留并分组**（通用/热键/显示器/剪贴板/外观） |
| 菜单栏常驻 | ✅ | ✅ | 一致，不画进窗口 |
| 画面归属 / 切屏 | ❌ | ✅ 核心 | **新增**（状态卡三态 + 设备卡 ×2 + 切换按钮） |
| 远端代发切换 | ❌ | ✅ | 融进切换按钮文案与流程 |
| AI 工具 / 搜索引擎 | ✅ | ❌ | **不要** |
| 日历 / 截图 / 取色 | ✅ | ❌ | **不要** |
| Pro 订阅 | ✅ | ❌ | **不要** |
| 悬浮剪贴板 | ✅ | ❌ | **不要**（违反「单一窗口」硬约束） |

## 2. 从 Frset 借的设计规则（不是素材）

版权红线：Frset 的 SVG/文案/插画**不能拷贝**，这里只借规则：

1. **单强调色** `#4E87FF`，主按钮扁平填充（去掉现有 PRIMARY_TOP/BOTTOM 渐变按钮）
2. **图标三档** 20px（工具行）/ 24px（强调）/ **44px（列表类型图标）**
3. **行的解剖**：图标 + 主文案 + 副行（`来源 · 时间 · 大小 · 类型`，2px 圆点分隔）
4. **空态 = 插画 + 主副文案**；且**「筛选无结果」与「本来就是空」文案分开**
5. **状态药丸即按钮**：失败 / 仅本机态点药丸直接重试
6. **设置分组小标题**，不再平铺长列表
7. 明暗靠 CSS 变量切换（对应 NSAppearance，不是两套颜色资产）

## 3. 保留的既有硬约束（不因重做而推翻）

- **整个应用只有一个窗口** —— 剪贴板 / 设置都是窗口内翻页（‹ 返回），不是独立面板
- 画面归属**三态**：windows / mac / unknown；unknown 时按钮置灰、设备卡「未连接」
- 剪贴板**「仅本机」与「失败」必须分开**（前者不是错误，不该报警）
- 来源图标**看来源不看本机**
- 「不提供清空对端」「敏感内容既不传也不记录」
