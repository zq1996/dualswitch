为什么不再开一个窗口

多窗口的系统性代价不在"多画一个 520×620"，而在于：多一个任务栏项 / 程序坞项、 多一套窗口位置记忆、多一处"关掉了但进程还在"的困惑、多一个 macOS 上要点两次才回到主界面的层级。

这个工具的窗口本来就是低频的（99% 时间靠热键和托盘），低频界面再分层，用户就得记"我要找的东西在哪个窗口里"。

为什么 440 宽够用

剪贴板页不需要和主页面并排看，所以不需要宽。440 − 36 内边距 = 404： 36 缩略图 + 10 间距 + 250 文字 + 64 状态药丸，正好。

高度更不是问题：主窗口本来就是可变的 —— 横幅出现时会长高 54px， 设置页用的是另一套高度。剪贴板页沿用 SETTINGS_H 即可，不需要改窗口尺寸。

入口带角标

「剪贴板」行右侧的「3 条新」只数从对端收到、你还没看过的条数。 进入页面即清零。它替代了托盘气泡 —— 不打扰，但你知道有东西进来了。

页头40「‹ 返回」+ 页名 + 右侧连接状态（对端名 + 绿点）

行高52比主页面列表行（42）高 10，因为要放两行文字；缩略图 36
状态色 已同步 传输中 失败 仅本机 四态互斥，沿用主窗口的语义色

不需要改主窗口尺寸。440 宽装得下，600 高正好（594）。如果以后要加"搜索框"或"按类型筛选"， 再统一把 theme.WIN_W 调到 480 —— 那是一次全局调整，不应该为了一个页面单独改。

05

行为

与主页面/设置页一致的规则

导航只有一条路：主页面 →「剪贴板」→「‹ 返回」→ 主页面。 没有常驻侧边栏、没有页签条 —— 三个页面（主 / 剪贴板 / 设置）都是"进去、看一眼、回来"， 平级堆叠会把低频操作变成常驻视觉噪音。

标题栏文字跟着变：`屏幕切换` / `屏幕切换 · 剪贴板` / `屏幕切换 · 设置`。 任务栏悬浮时能看出当前在哪一页，不用点开。

Esc 和「‹ 返回」等价；窗口关闭 = 收进托盘，不会只关掉某一页。

进入页面时刷新一次，离开时停止轮询。面板不可见时不做任何 UI 更新， 避免低频页面在后台空转。

清空的两层语义

「清空记录」只清列表，不动系统剪贴板 —— 删了还能粘，可反悔。

「清空本机剪贴板」放在选中行右键菜单里，是系统操作。

不提供「清空对端」：能远程清别人剪贴板的工具，没人敢用。
