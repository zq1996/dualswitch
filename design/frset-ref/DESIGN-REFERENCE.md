## 1. 应用形态（决定页面架构的那部分）

Frset 是 **菜单栏常驻工具**（`LSUIElement=true`），不是 Dock 应用。这与 dualswitch mac 端定位完全一致：

| | Frset | dualswitch mac（现状） | 建议 |
|---|---|---|---|
| 主入口 | 菜单栏图标（`abc_menuIcon` 20×20 模板图） | 菜单栏图标 18×18 模板图 | 保持，尺寸统一到 **20×20**（见 §3） |
| 窗口 | 主窗 776×490 + 悬浮剪贴板 | 主窗 440×600 | 按 §4 讨论 |
| 设置 | 同一 app 内独立窗口，**侧栏 4 分组** | 同一窗口内翻页（‹ 返回） | 保留单一窗口铁律，但侧栏分组思路可借鉴（§5） |
| 退出 | 菜单栏「退出」 | `⌘Q` / 菜单栏 | 已一致 |

Frset 主窗 776×490 是「常开浮窗」尺度（列表 + 预览双栏）；dualswitch 主窗是 440×600 紧凑卡片。
**不建议照搬 776 宽** —— dualswitch 一次只关心「当前画面 + 一个切换动作」，信息密度远低于剪贴板管理器。
可参考的是它的 **行高/图标配比**，不是窗口尺寸。

## 2. 设计令牌（从资产反推）

### 2.1 颜色

只有 **一个** Color 资产：

```
AccentColor = sRGB(0.306, 0.529, 1.0) = #4E87FF
```

- 全局单强调色，没有第二品牌色
- 亮暗两套靠 `NSAppearance`（资产表里 `Aqua:8 / DarkAqua:1`），**不是靠再定义一组颜色资产**
- 启发：dualswitch 现在 `PALETTE` 里 accent/accent_deep/accent_soft 三档渐变按钮是自己发明的视觉，
  Frset 走的是「一个强调色 + 系统材质」路线，更 macOS。重做时**建议收敛到单强调色 + 系统灰阶**，
  按钮渐变（`PRIMARY_TOP`/`PRIMARY_BOTTOM`）属于 Windows 端遗留观感，mac 端可考虑换扁平/填充 + 系统强调色。

### 2.2 图标尺寸体系（最有价值的一条）

Frset 的图标是**按用途分档**的，不是一套字号拉伸：

| 档位 | 尺寸 | 用在哪 | 资产举例 |
|---|---|---|---|
| 菜单栏 | 20×20 | 菜单栏模板图 | `abc_menuIcon`, `abc_menuIcon_pause` |
| 工具条 | 20×20 | 主窗工具行小图标 | `abc_clear`, `abc_settings`, `abc_screenshot`, `abc_float`, `abc_colorpicker`, `abc_eyedropper` |
| 工具条（大） | 24×24 | 需要更重的存在感 | `abc_color`, `abc_fan`, `abc_more` |
| 设置侧栏 | 24×24 | 设置页导航项 | `settings_*` |
| 剪贴板类型 | **44×44** | 列表行左侧类型图标 | `clipboard_type_text/url/color/unknow` |
| 空状态插画 | 72×55 | 列表空态 | `clipboard_empty` |
| 徽章 | 24×12 | Pro 标 | `abc_proBadge` |
| 状态微标 | 8×18 / 12×12 / 14×10 | 网速 / 内存 / 光驱 | `abc_menuNet`, `abc_ram`, `abc_disc` |

**全部矢量 SVG，全部 1x/2x 成对**，命名 `foo.svg` + 尺寸记录，不是位图切图。

对 dualswitch 的直接可执行结论：
1. **行内类型图标从现在的 ~16px 提到 36–44px**（Frset 44 是给「剪贴板条目」这种可点选行用的，
   dualswitch 切换行/剪贴板行同理需要一眼可辨的类型图标）
2. 菜单栏图标 18×18 → **20×20**（与 Frset 及 macOS HIG 一致）
3. 小图标统一 **20×20**，需要强调的 **24×24**，不要再出现第三种尺寸
4. 图标一律矢量（或 1x/2x 位图成对），沿用现有 `theme.asset()` 加载

### 2.3 亮暗成对规则（重要）

不是所有图标都做暗色版。Frset 的规则是：

- **模板图**（菜单栏、单色工具图标）→ 不做暗色版，靠 `NSImage.isTemplate` 系统反色
  - `abc_clear` / `abc_settings` / `cal_*` 等只有一套
- **带自身品牌色/填充色的** → 做 `*_dark` 成对
  - `abc_frset` ↔ `abc_frset_dark`（logo，54×17）
  - `color_grid_light` ↔ `color_grid_dark`（180×180 取色网格）
  - `settings_proBadge_light` ↔ `settings_proBadge_dark`
- **选中/未选中三态** → 设置侧栏 24×24 每项三份：
  `settings_general_selected_light` / `settings_general_selected_dark` / `settings_general_unselected`

dualswitch 现状是单套亮色主题（`SOUL` 提到设置页只管亮色）。如果要跟系统外观走，
最省事的路径就是抄这个三件套模式：**未选中一份 + 选中亮/暗两份**，其余单色走模板图。

## 3. 菜单栏（Frset 字段）

```
abc_menuIcon        20×20   常态
abc_menuIcon_pause  20×20   暂停记录剪贴板时
abc_menuNet          8×18   网速微标
abc_fan             24×24   动态风扇（转速随 CPU）
abc_ram             12×12   内存微标
```

- 菜单栏图标是**模板图**，明暗自动适配
- 有「暂停」状态切换图标（不是灰掉，是换图）
- 可选的监控微标（网速/内存/风扇）是**独立小尺寸资产**，叠在主图标旁边

dualswitch 对应点：菜单栏图标应支持「正常 / 探测中 / 异常」至少两态，
现在只有一张 `menubar.png`。尺寸统一 20×20。

## 4. 主窗口结构

Frset 主窗 **776×490**，从文案可还原出的分区：

```
┌──────────────────────────────────────────────┐
│ 标题栏（可拖动 · "Drag title bar to move"）      │
├──────────────────────────────────────────────┤
│ FilterBar：[返回] [搜索…] [回到顶部]             │
├───────────────┬──────────────────────────────┤
│ 列表（行）      │ 预览区（Quick Preview /        │
│  行类型图标      │  Markdown Preview /           │
│  44×44         │  JSON Formatted Preview）      │
│  内容 + 元信息   │                              │
│  %d 行 · %d 字  │                              │
└───────────────┴──────────────────────────────┘
```

关键交互词汇（直接可复用的中文表达）：
- 行元信息：`%d 行 · %d 个字符`
- 复制反馈：`%@ 已复制` / `已复制 %d 项`
- 空态主标题：`复制内容后会显示在这里`
- 空态副标题：`剪贴板为空`
- 筛选空态：`当前筛选下暂无内容` / `换个筛选条件试试`
- 双击/回车复制：`双击或按 ↩ 复制`
- 预览：`单击或按空格预览`

**对剪贴板列表页（`clipboard_page.py`）重做最有用的三条**：
1. 行 = **大类型图标(44) + 正文 + 次要元信息行**，现在是小图标挤在左边
2. 空态要**插画 + 主副文案**（`clipboard_empty` 72×55 那种），不是干巴巴一行字
3. 筛选无结果与「本来就是空的」**文案分开**（Frset 明确分了两条）

## 5. 设置页

Frset 设置是**侧栏 4 项**，每项 24×24 图标 + 文案：

| 侧栏项 | 中文 | 资产 | 页内内容（从文案反推） |
|---|---|---|---|
| 通用 | 通用 | `settings_general_*` | 语言、外观、字体大小、启动时打开、高级 |
| 主界面 | 主界面 | `settings_window_*` | 菜单栏图标、显示菜单栏图标、悬浮剪贴板、动态风扇 |
| Pro | Pro | `settings_pro_*` | 订阅、Pro 徽章、权益 |
| 关于 | 关于 | `settings_about_*` | 版本、许可证、导出/导入设置 |

**外观分段控件**（值得照搬的表达）：

```
外观:  [跟随系统] [浅色] [深色] [Midnight]
```

外加可选的 `展示一行 / 展示两行`（列表密度）和 `字体大小`。

dualswitch 设置页现状是「一个长列表 + ‹ 返回」。按铁律（单一窗口）保留翻页模式，
但**可以借鉴的是分组标签**：把设置项按「通用 / 窗口 / 关于」贴小标题，
而不是全部平铺。侧栏改成翻页 Tab 也能做（顶部胶囊 Tab），仍是单窗口。

## 6. 这次没拿到的（以及怎么补）

| 缺口 | 为什么 | 补法 |
|---|---|---|
| 像素级视觉（圆角/阴影/间距/渐变） | 资产只给尺寸不给渲染参数 | **需要截图**。`screencapture` 被沙箱拦了写入；下次你在本机手动 `screencapture -x` 截 Frset 主窗/设置窗丢给我即可 |
| SwiftUI 视图层级 | 二进制 strip，RE A 需 Hopper/Ghidra（本机没装） | 装 Hopper 后 `rea analyze` 可出伪代码，但**对纯视觉重做不是必需** |
| 字体 / 字号具体值 | 资产不含排版 | 从截图量；Frset 有 `Font Size` 用户可调，说明用的是动态字号 |

| 项 | 现状 | 参照 Frset 的改法 |

## 8. 结论

**REA 解析本身可用**，`inspect-asset-catalog` 一条命令就把 101 个资产名、尺寸、亮暗配对全部吐出来了，
这是本次最值钱的产出。受限于本机没装 Hopper/Ghidra，二进制级反编译走不通，
但页面重做需要的**规格层**证据已经够了。

**下一步建议（按优先级）**：
1. 你手动截 Frset 主窗 + 设置窗（亮/暗各一张）丢进 `design/frset-ref/`，我来量圆角/间距/字号
2. 先做 §7.3 剪贴板页行布局改造（44px 类型图标 + 元信息行 + 空态插画）—— 收益最直接
3. 图标尺寸体系统一（20/24/44 三档）并换成矢量
4. 再考虑暗色支持（三态图标模式已摸清）

**红线提醒**：Frset 的 SVG 资产、文案、插画都是它的版权素材，**只能参考尺寸与布局规则，不能直接拷贝文件**。
dualswitch 要自己画图标或用开源图标库。
