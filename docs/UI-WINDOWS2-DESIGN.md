# Windows 端 v2 界面设计（Windows2）

> 2026-10-21 · 对应原型 `design/windows2/index.html`（浏览器直接打开，可点）
> 规格来源：`design/redesign/INTERACTIONS-v2.md`（交互真源）+ `design/redesign/index-v2.html`（视觉基准）
> 落地参考：`src/dualswitch/ui/mac2/**`（mac 端已实现并验收过的同一套交互）

## 0. 一句话

**同一套产品、同一套骨架，换一副 Windows 的壳**：780×580 宽窗口 + 188 侧栏 + 三页（切换 / 剪贴板 / 设置）+ 30px 底栏；
常驻入口从「菜单栏图标」换成「托盘图标」；快捷键从 `⌥Space / ⌘⇧V` 换成 `Alt+Space / Ctrl+Shift+V`；
打开方式从「访达 / Preview.app」换成「资源管理器 / 默认看图 / 默认浏览器」。
视觉令牌、行高、缩略图、角标、预览窗时序、四态药丸全部沿用，不重新发明。

## 1. 依据与边界

### 1.1 三条硬约束（不因平台重做而推翻）

| 约束 | 出处 | Windows2 遵守方式 |
|---|---|---|
| 整个应用只有一个窗口 | 用户 2026-10-18 | 切换/剪贴板/设置都是窗口内换页；预览气泡是悬浮层；清空确认改成**窗口内遮罩**（比 mac2 的 QDialog 更彻底） |
| 画面归属三态，unknown 必须置灰 | ISSUE-001 | 照搬 mac2 的三态表，只换文案里的「访达/菜单栏」等平台词 |
| 「仅本机」≠「失败」 | `UI-DESIGN-CLIPBOARD.md` | 四态药丸语义不变：灰=仅本机（可重试，不是错），红=失败 |
| 来源看**系统**不看本机 | `INTERACTIONS-v2.md` §3.3 | 角标 = Windows 蓝牌 / Mac 灰牌；应用名只进元信息文字 |
| 不提供「清空对端」 | `CLIPBOARD-SYNC-CONTRACT.md` | 清理只清本机列表 |
| 文件不跨端（P2） | 同上 | 文件记录只可能本机产生；「在资源管理器中显示」语义成立 |

### 1.2 三条平台差异原则

1. **系统惯例优先**：Windows 用户对托盘、标题栏、菜单、右键的预期和 macOS 不同，不硬抄 mac 的手感。
2. **已有实现优先**：Windows 端现在是「无边框自绘标题栏 + 拖拽 + 托盘降级链」，这套是踩过坑调通的，不为了对齐 mac 而换回系统标题栏。
3. **后端能力优先**：设计里出现的每一类记录，都要能在 Windows 后端真的产生（否则标为「待后端」，见 §11.4）。

## 2. 与 mac2 的差异总表（先看这张）

| 维度 | mac2（已实现） | Windows2（本设计） | 原因 |
|---|---|---|---|
| 窗口边框 | 系统标题栏（红绿灯 + 居中标题） | **自绘无边框标题栏** 40px：左「图标 + 屏幕切换」，右 最小化 / 关闭 | Windows 没有红绿灯；现有 `chrome/win.py` 的拖拽/圆角/降级链已调通 |
| 标题栏按钮 | 无（只有系统红绿灯） | 仅 最小化 / 关闭（46×32，Win11 规格）；**不放剪贴板/齿轮** | 保留窗口操作是 Windows 必需；功能入口统一走侧栏 |
| 窗口圆角 | 16 | **12** | 贴近 Win11 窗口观感（系统窗口约 8，自绘取 12 不显钝） |
| 字体 | SF Pro Text / PingFang SC | **Microsoft YaHei UI → Microsoft YaHei → Segoe UI Variable Text → Segoe UI → Segoe UI Emoji**（10-21 按反馈改成雅黑打头，见 §3.3） | 中文界面在 96dpi 下雅黑比 Segoe 的 CJK 回退清楚 |
| 元信息灰度 | `ink3 #8A93A3` | **`#7A8494`（提深一档）** | 微软雅黑 10px 比苹方更糊，原灰度对比不足 |
| 常驻入口 | 菜单栏图标：单击弹菜单、双击开窗 | **托盘图标：左键开窗、右键菜单、双击也开窗（不切换）** | Windows 托盘惯例；双击切换是重操作，误触成本高（现有实现已定这条） |
| 菜单 | NSMenu（系统画，键帽用 keyEquivalent） | **QMenu + QWidgetAction 自绘行**（键帽与窗口内完全一致），兜底退化为原生 QAction + 右对齐快捷键文本 | QMenu 原生行高/字体不受控；自绘能保证 32px 行高与键帽观感 |
| 菜单危险色 | 退出 = 系统红 | **退出用普通色** | Windows 菜单没有「红字菜单项」惯例 |
| 全局热键 | `⌥ Space` | **`Alt + Space`** | Windows 默认配置；与系统窗口菜单冲突 → 必须开「阻止 Alt+Space 弹出系统菜单」 |
| 剪贴板热键 | `⌘ ⇧ V` | **`Ctrl + Shift + V`** | Windows 惯例 |
| 键帽字形 | `⌘ ⌥ ⇧ ⌃` 符号 | **`Ctrl` `Alt` `Shift` `Win` 文字**；单键最小宽 22，`Space` 34 | Windows 键帽不印符号；文字键帽需要更宽 |
| 图片打开 | Preview.app（临时 PNG） | **系统默认图片查看器**（`os.startfile`，通常是「照片」） | 平台默认 |
| 文件定位 | 访达 `activateFileViewerSelecting` | **资源管理器** `explorer /select,"<path>"` | 平台默认 |
| 链接打开 | `NSWorkspace.open` | **默认浏览器**（`webbrowser.open`） | 平台默认 |
| 来源应用图标 | bundle id → `NSWorkspace` 图标 | **exe 路径 → `QFileIconProvider` 图标** | 后端能力不同 |
| 清空确认 | 独立 `QDialog`（340 宽） | **窗口内遮罩 + 360 卡片**，`Esc`/点遮罩取消 | 更彻底地守「一个窗口」 |
| 设置页 | 四组（通用/剪贴板/热键/显示器） | **五组**：多一个「高级」（探测显示器 / 查看日志 / 打开配置目录） | 这三项从托盘日常菜单里移出（mac2 §1 也这么要求，只是没落地） |
| 主题 | 仅浅色 | **仅浅色** | 与 mac2 同一决定，不引入深色维护面 |
| 后台通知 | 菜单栏气泡 + 日志 | **系统通知（托盘气泡）**；窗口在前台时改用窗口内 toast | 避免同一次切换弹两次 |
| 配对页（2026-10-22 新增） | `ui/mac2/pairing_page.py`，7 状态 | **照同一套状态机自建** `ui/win2/pairing_page.py`：托盘菜单 + 侧栏两个入口、「替换配对」用窗口内遮罩而不是 `QDialog` | 底层 `sync/*` 共享，只有界面各写各的（见 §14） |
| 侧栏宽度 | 156，可收到 56 | **188（暂不跟改）**，收起把手待定 | Windows 侧栏标题更长、系统级「收起侧栏」不是习惯；先保持现状，等 §14.2 拍板 |

### 3.3 字号与字体

> **2026-10-21 按用户反馈改过一版**（原稿是 Segoe UI Variable Text 打头 + 12.5/10.5/9.5 三档）。
> 原因：96dpi 下中文全靠回退到雅黑，12px 的回退字形又细又糊；`9.5/10.5` 这类半像素字号
> 还会被 Qt 四舍五入成 10/10，等于两档挤成一档。改后逐张出图核对过没有挤版。

- 全局 `setPixelSize(13)`；QSS 全部写整数 `Npx`（**不要 point**，96dpi 下 point 会放大 1.33 倍；
  也不要写 `12.5px`，Qt 会自己取整）。
- 档位：27（hero 名）/ 14（行题·主按钮·设备名）/ 13（正文·导航·搜索）/ 12（小字·副行）/
  11（分组标题·元信息·键帽外的小字）/ 10（药丸·导航徽章·键帽）。
- 字体族：`Microsoft YaHei UI, Microsoft YaHei, Segoe UI Variable Text, Segoe UI, Segoe UI Emoji, sans-serif`；
  等宽：`Cascadia Mono, Consolas, monospace`。emoji 显式列 `Segoe UI Emoji`（别指望隐式回退）。
- `qfont()` 的像素取整用 `int(px + 0.5)`（向上取整），别用 `round()`：`round(12.5)=12` 会把正文压回一档。
- DPI：100/125/150% 都按逻辑像素布局；图标按 `devicePixelRatio` 超采样（沿用 mac2 `icons.py` 的缓存键）。

### 3.3.1 Qt QSS 的一个坑：圆角超过半高 = 没有圆角

`border-radius: 999px` 这种「胶囊写法」在浏览器里是标准做法，**Qt QSS 会整条忽略**
（不是夹紧到半高，是直接当没写）—— 表现就是药丸变成直角矩形。2026-10-21 用户截图里的
「运行中」方角就是这个原因，mac2 也有同一处。

规则：圆角一律写具体值，且 **严格小于控件高度的一半**（19 高的药丸连 10 都不行）。
本项目：chip（24 高）12、设备标签（约 21 高）10、键帽（18 高）5、卡片 12。
`tests/test_ui_win2.py::test_qss_has_no_oversized_radius` 会拦「超过 12px 的圆角」。

**19px 高的药丸干脆自绘**：`widgets.Pill` 在 `paintEvent` 里用「高度/2」当半径画圆角矩形，
不跟 Qt QSS 的圆角较劲（2026-10-21 实测：19 高 + 9/10/999px 全是方角，同高度 21px 的标签却正常）。

## 4. 托盘（Windows 的「菜单栏」）

### 4.1 交互

| 操作 | 行为 | 备注 |
|---|---|---|
| 左键单击 | 打开主界面并置前 | Windows 惯例；**不切换画面** |
| 双击 | 同左键（打开主界面） | 兼容旧版；两次单击不会连切 |
| 右键 | 弹菜单 | 菜单是唯一「随手切一下」的入口 |
| 悬停 | tooltip：`屏幕切换 · Alt Space · 当前画面：Windows` | 250ms 轮询更新 |
| 托盘不可用 | 窗口关闭 = 最小化；启动横幅提示「托盘不可用，关窗后请从任务栏恢复」 | 现有 `_disable_tray_hiding` 逻辑保留 |

> **为什么不照抄 mac 的「单击弹菜单」**：Windows 托盘左键单击默认就是「打开程序」，改成弹菜单会让 90% 的用户第一次点空。
> 菜单在右键，是 Windows 用户的肌肉记忆。

### 4.3 通知

- 窗口不在前台：`QSystemTrayIcon.showMessage("屏幕切换", "已切换到 Mac · 63.9 ms")`。
- 窗口在前台：窗口内 toast（1900ms），不弹系统通知。
- 失败：系统通知 + 主界面注脚变红「切换失败，详见日志」。

### 6.6 预览气泡

- **位置**：缩略图左侧 12px，箭头朝右指向缩略图；左侧放不下翻右侧；垂直对齐缩略图中线并夹在窗口内。
  气泡是**顶层悬浮层**（`Qt.ToolTip`/无边框窗口），可以超出主窗口边界。
- **时序**：开 450ms / 关 220ms；气泡自身 hover 保持打开；滚动、换页、换行、窗口失焦立即关。
- **尺寸**：随内容自适应；图 ≤412×330（只缩不放）；文字 ≤392 宽、高度上限 = `min(屏幕可用高 − 120)`；
  代码 ≤400；文件卡 ≤380。文本**不截断**：超屏时正文内部滚动；>2 万字才限渲染量并注明。
- **结构**：头（类型图标 14 + 标题 + 药丸，`card-2` 底）/ 正文 / 底栏（`来源 · 应用 · 时间 · 大小` + 按钮）。
- **视觉**：圆角 13，三层阴影，入场 `scale(.96→1) + fade` 180ms（弹簧感 320ms 曲线）。

> **2026-10-21 补的两处（用户截图反馈）**
>
> 1. **阴影要真画**。气泡是 `WA_TranslucentBackground` 的顶层窗口，卡片本身是 `#FFFFFF` ——
>    压在白色主窗口上完全分不出边界（「融到一起了」）。实现：窗口四周留 `SHADOW=14` 的透明边，
>    `paintEvent` 里画 14 层递减透明度的圆角矩形当投影；卡片（`_inner`）内缩 14px。
>    因此 `bubble.size()` = 卡片 + 箭头 12 + 阴影 14×2，**尺寸上限说的是卡片**。
> 2. **长 URL 不能裁**。整条 URL 是一个「词」，`QFontMetrics.boundingRect` 的折行规则和
>    `QTextLayout` 不一致：它算成 1 行，实际排了 2 行，于是第二行被固定高度裁掉（截图里只剩
>    `https://www.bilibili.com/?`）。量高必须用 `QLabel.heightForWidth(width)`。

文件卡（图片文件也走这张卡）：

```
        [ 文档图标 + PNG ]        ← 52px 字形 + 扩展名
        湖畔的清晨.png            ← 12/650，居中，≤2 行
        ~\Downloads\照片          ← 10px，居中
────────────────────────────────
3.0 MB · 14:33   [预览][打开文件][复制]
```

### 6.9 Windows 后端的两个缺口（**两个都已补齐，2026-10-21**）

1. **来源应用（已实现）**：`clipboard/windows.py` 读到新内容时抓前台窗口 → 进程 exe 路径 →
   `FileDescription`（本地化显示名：`Windows 资源管理器` / `记事本` / `微信`），exe 路径当 `app_id`。
   列表于是显示 `Windows · [14px exe 图标]微信 · 3 分钟前 · …`；截图工具（Win+Shift+S）按 mac 口径
   统称「截图」。拿不到就只显示来源系统名（不占位、不留空）。
   · 抓的是 **poll 时刻**的前台，和真正按 Ctrl+C 差 150ms 以内；自己写的剪贴板会被 poll 吞掉，
     所以不会把「屏幕切换」记成来源；
   · 显示名按 exe 路径缓存（读版本信息不便宜，不能每次 poll 都查）。
2. **文件记录（已实现）**：`clipboard/windows.py` 解析 `CF_HDROP` → `make_file()`：
   · 图片文件读文件抽缩略图（最长边 ≤1600px，PySide6 → Pillow 解码器，都没有就只记文件名）；
   · 其它文件只取文件名 + 目录 + 字节数；文件已被删掉时退回文本（不留打不开的文件卡）；
   · 多选只记第一个（契约里一条内容一个 `path`）；
   · 8.3 短路径（`ADMINI~1`）转长路径，`~\Downloads` 缩略与去重指纹才对得上；
   · 「复制」会把 `CF_HDROP` 写回剪贴板（粘到资源管理器是文件，粘到输入框是文件名）；
   · 文件本身仍不跨端（`path` 不上网），图片文件按图片照常同步。
   `probe()` 里多了 `files=N`，排障时先看它解析出几个路径。

## 11. 验收清单（照着点一遍）

1. 窗口能拖动；右上角只有 最小化/关闭；hover 关闭变红；没有多余的剪贴板/齿轮按钮。
2. 侧栏三页可切，选中态主色实底；剪贴板行显示条数徽章。
3. 托盘：左键单击开窗；右键出菜单；双击也只开窗（**不切换**）；菜单 8 行文案与状态灯正确。
4. 切换页：断显示器时按钮/设备卡置灰、字看得清、不显示键帽；对端在线时出现「从 Mac 切过来」。
5. 点主按钮 → 「切换中…」→ 状态翻转 + toast；失败时注脚红字。
6. 剪贴板：单击任意行 = 复制（toast）；双击 = 预览；悬停缩略图 450ms 出气泡，移出 220ms 关。
7. 重复复制同一段文字 → 不多一条，原条跳到最上面。
8. 长文本气泡全文显示，超屏时内部滚动，没有省略号和「已显示 N 字」。
9. 截图只有「预览」；文件只有「在资源管理器中显示」；链接只有「打开链接」。
10. 🗑 → 窗口内遮罩确认（红色「清空」）后才清空；行内 × 只删一条；`Esc` 能取消。
11. 设置页改动即时生效并落盘；键帽点击进入录制，`Esc` 取消；存储上限可输入 + 清理可用。
12. 关闭窗口 → 收进托盘；托盘「退出」才真退出；托盘不可用时关窗最小化并有提示。

| 1 | `Alt+Space` 是系统窗口菜单，不吞键会先弹菜单 | 默认开「阻止 Alt+Space 弹出系统菜单」；钩子后端不可用时降级为 `Ctrl+Alt+Space` 并在设置页提示 |

### 14.5 不需要做的（避免白干）

- **不要**在 Windows 侧重写配对底层（`derive_key` / `set_key` / 落盘）：`sync/*` 是共享层，pull 即可。
- **不要**给 UDP 广播加自定义字段 —— 有需求先写进契约 §11。
- **不要**把 `pairing` / `paired` 当必填：老版本对端没有这两个字段，缺失时按「未配对/未知」处理，不报错。

### 14.6 验收

1. `pytest -q` 全绿（含共享用例 `tests/test_pairing.py`、`tests/test_source_state.py`）。
